# Marine Wave Data Pipeline & Analysis

## Project Overview
This project uses the Open-Meteo Marine API to retrieve hourly wave-height data and analyze marine conditions using Python, PostgreSQL, SQL, and Tableau Public.

The goal is to demonstrate how API data can be extracted, stored, transformed, analyzed, and presented through an interactive dashboard.

## Technologies Used
- Python
- Open-Meteo Marine API
- PostgreSQL
- pgAdmin
- SQL
- Tableau Public
- Jupyter Notebook

## Project Workflow
1. **Data Extraction:** Retrieved hourly wave-height data from the Open-Meteo Marine API using Python.
2. **Data Loading:** Loaded the API data into PostgreSQL.
3. **Data Transformation:** Cleaned and categorized wave-height observations using SQL.
4. **Data Analysis:** Created SQL queries and views to calculate daily averages, minimums, maximums, and wave-category distributions.
5. **Data Visualization:** Exported analytical results and created an interactive Tableau dashboard.

## Dashboard
[View the Interactive Tableau Dashboard](https://public.tableau.com/app/profile/danielle.jaggan/viz/marineapi/Dashboard1)

## Analysis
The project explores:
- Daily average wave height
- Daily highest and lowest wave heights
- Distribution of low, moderate, and high wave conditions
